# Implementation Plan

本计划落实用户版全部既有本地模型用途经引擎接入中心，以及服务器最终导出时长策略和指定素材的一条真实高光成片。规格生成不等于实施完成；所有实现项初始未勾选。每个任务先补确定性失败测试，再写最小实现，真实产物/推理/GUI/媒体验证分别记录，不以mock或资产存在替代。

已完成前置动作：基线3572089已提交推送至origin/r3-dev2；本计划不再自动提交推送、发版、升版或部署。旧local-model-center规格的未完成项继续保留，不在本轮批量改勾。GUI仅允许热重载，不kill、不大写R、不重打包或擅自hot restart。

## Dependency Order

- 波次A：1协议边界；10服务器策略可独立并行。
- 波次B：2绑定 → 3会话 → 4媒体 → 5作业；6原生Whisper实现可按文件边界并行。
- 波次C：7文本/视觉、8冻结音色、9Go Haar独立适配；共用清单/构建文件统一集成，避免竞写。
- 波次D：11高光链 → 12最终时长 → 13三端UI与依赖。
- 波次E：14真实构建/逐能力/GUI → 15指定真实素材成片。

每项只有在实现与对应测试实际通过后勾选；未运行干净环境、未生成原生流式产物、未真实加载某模型或未取得GUI画面均不得标为已验收。此文件是后续编码清单，不是测试报告。
