# Implementation Plan

> 用户已明确“执行所有任务”。本计划已纳入 Requirement 1–14 的96条验收条件，按依赖波次批量执行；仅将实现与相应测试实际通过的任务勾选。缺失构建输入、未生成产物、未运行的干净环境与真实界面验收不得标为完成。

下列任务仅列编码与自动化测试任务。已提交的 Go 初稿不等于已完成以下任务。修改范围包括独立中心、显式构建脚本与输入、必要 module 引用及三端既有区域的入口、可见性与依赖检查集成；不改授权协议、不自动迁移现有模型配置、不下载、清理或执行模型。

执行前重新读取三份规格；按任务依赖推进，先补确定性失败测试，再修改实现。顶层任务只有在其子任务与相应验证全部完成后才能勾选。本轮按用户明确授权批量执行，不逐项停顿；并行任务隔离文件边界，汇总后核对真实差异并运行集成测试。
